# Data Analytics Projects

Collection of data analytics projects focused on SQL, Python, Tableau, Power BI, data cleaning, and visualization.

## Projects

### Sales Insights Dashboard | SQL, Tableau
- Analyzed sales and customer data using SQL to identify revenue trends, product performance drivers, and user behavior insights.
- Developed interactive Tableau dashboards and validated MySQL datasets to improve KPI tracking and reporting accuracy.

### SQL Data Cleaning & Validation Project | SQL
- Cleaned and standardized raw datasets using SQL by removing duplicates, correcting inconsistencies, and validating data integrity.
- Improved reporting accuracy and downstream analysis readiness through structured data cleaning processes.

### Air Quality Dashboard | Python, Power BI, Snowflake, SQL
- Built an end-to-end air quality analytics pipeline using Python, Snowflake, SQL, and Power BI.
- Ingested, cleaned, and visualized OpenAQ PM2.5 sensor data to analyze global air quality trends.

## Tools & Technologies
- SQL (MySQL)
- Python (Pandas, NumPy)
- Tableau
- Power BI
- Snowflake

## Repository Structure
Each project folder contains relevant SQL scripts, Python files, dashboard screenshots, and supporting documentation.
